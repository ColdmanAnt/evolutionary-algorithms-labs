## Установка и запуск

Требуется Python 3.12+, NumPy и Matplotlib. Можно использовать уже активированное окружение из [корневой инструкции](../README.md). Если создаёте отдельное окружение из папки `lab3`:

```sh
python -m venv .venv
```

Активация в macOS/Linux: `source .venv/bin/activate`. В Windows PowerShell: `.\.venv\Scripts\Activate.ps1`; в командной строке Windows: `.venv\Scripts\activate.bat`. После активации во всех системах используйте обычную команду `python`:

```sh
python -m pip install -r ../requirements.txt
python lab3.py --runs 20 --budget 240 --output results
python -m unittest -v test_lab3.py
```

Повторить приложенный эксперимент с перезаписью результатов рядом с кодом:

```sh
python lab3.py --runs 20 --budget 240 --output .
```

`--runs` задаёт число независимых seed 100, 101, …; `--budget` — точный лимит обращений к fitness, включая первоначальную популяцию и попадания в кэш. На каждую конфигурацию λ приходится заданное число запусков. Меняется только коэффициент штрафа сложности (0 / 0.004). Все прочие настройки фиксированы в `config.json`.

## Результаты и воспроизводимость

- `data.csv` — все входные данные, метки, фиксированное train/validation/test-разбиение.
- `runs.csv` — победители запусков, seed, fitness, исходная ошибка, сложность, test-метрики, время, число оценок и фактических обучений.
- `history.csv` — лучшая оценка после каждого обращения к fitness.
- `evaluated_architectures.csv`, `pareto_archive.csv` — проверенные архитектуры и внешний архив.
- `selection_before_test.json` — три решения, выбранные по validation до тестовой оценки.
- `representatives.csv`, `model_1.npz`–`model_3.npz` — три решения и их веса, scaler, генотип.
- `convergence.png`, `quality_complexity.png`, `algorithm_flow.png` — графики и схема.
- `results.json`, `report_content.json` — сводные числа и материалы PDF-отчёта.

Test не участвует в обучении весов, fitness, архиве и выборе моделей. Кэш разделяется по запуску и конфигурации; инициализация детерминирована seed и генотипом. Бюджет одинаков в обращениях к fitness, но число фактических обучений может отличаться — оба значения сохранены. Время зависит от оборудования и загрузки системы; сравнивать качество следует по фиксированным числам оценок.

## Интерпретация сохранённой модели

```python
import numpy as np
from lab3 import Gene, predict_logits, sigmoid
saved = np.load('model_3.npz')
gene = Gene(*map(int, saved['gene']))
weights = {k: saved[k] for k in saved.files if k not in ('mean', 'scale', 'gene')}
x = np.array([[0.2, 1.1, -0.3, 0.0]])
probability = sigmoid(predict_logits(gene, weights, (x - saved['mean']) / saved['scale']))
print(probability)
```

Данные синтетические и предназначены для учебной демонстрации. Малое пространство из 135 архитектур допускает полный перебор; эволюционный поиск здесь исследуется как метод. Глобальная оптимальность не гарантирована.
