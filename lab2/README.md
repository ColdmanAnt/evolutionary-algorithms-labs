# Лабораторная работа № 2 — расписание дежурств

Холодков Антон Евгеньевич, группа 517, номер 28. Вариант 10.

Требуется Python 3.12+, NumPy, Matplotlib. Создание и активация окружения описаны в [корневой инструкции](../README.md). Готовые оптимизаторы не используются.

Из папки `lab2` после активации окружения:

```bash
python -m pip install -r ../requirements.txt
python lab2.py experiment --runs 20 --budget 6000 --seed-start 0 --out .
python lab2.py single --method repair --operator replace --seed 0 --budget 6000
python -m unittest discover -s . -p 'test_*.py'
```

`experiment` заново генерирует фиксированный экземпляр (`data_seed=10010`) и перезаписывает результаты в `--out`. Для пробного запуска укажите другую папку, например `--out trial_lab2`. Данные намеренно синтетические; доступность исходного допустимого плана принудительно разрешена, чтобы исключить случайно неразрешимый экземпляр. Код `generate_data` и полный план находятся в `data.json`.

Пять сравниваемых конфигураций: `penalty_replace`, `penalty_swap`, `repair_replace`, `repair_swap`, `random_none`. Первые четыре образуют полный факторный план 2×2. Baseline строит независимые допустимые графики посредством того же ремонта. Каждый метод получает одинаковый исходный допустимый план. Бюджет считает полные вызовы целевой оценки, включая инициализацию и не вошедших в популяцию потомков. Проверки ограничений в ремонте не являются вызовом фитнес-функции; их стоимость учитывается во времени. Одна детерминированная проверка исходного плана при загрузке исключена из поискового бюджета у всех методов.

Файлы:

- `lab2.py`, `test_lab2.py` — реализация и проверки;
- `data.json`, `config.json` — экземпляр и параметры;
- `perrun.csv`, `histories.csv`, `solutions.json` — все запуски и траектории;
- `summary.csv`, `summary.json` — статистика с выборочным стандартным отклонением;
- `examples.json` — два допустимых и два недопустимых примера;
- `best_solution.json`, `best_schedule.csv` — лучший допустимый график;
- PNG — сходимость, разброс, график дежурств и схема алгоритма;
- [PDF-отчёт](../reports/lab2_report.pdf) — отчёт, созданный общим сборщиком комплекта.

Вектор хранит индексы сотрудников 0..6, а таблица расписания отображает номера 1..7. Нет утверждения о глобальной оптимальности. Это учебная модель, не проверка требований трудового законодательства.
