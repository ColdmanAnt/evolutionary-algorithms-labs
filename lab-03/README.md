# Лабораторная работа 3

Эволюционный синтез и многокритериальная оптимизация.

**Статус:** структура подготовлена, реализации и результатов пока нет.
**Вариант 16**, трек A/B ещё не выбран в [variant.json](../variant.json).
В документе нет однозначного правила выбора трека по V: варианты 1–20
перечислены в обеих таблицах.

Для варианта 16 предусмотрены:

- **Трек A — план закупок:** минимизировать затраты, риск дефицита и объём хранения.
- **Трек B — генерация эвристики для задачи рюкзака:** эволюция выражения
  приоритета предметов.

Перед реализацией требуется уточнить у преподавателя, какой трек использовать.

## Общие требования

Два противоречивых критерия либо сложная цель со сравнением качества и сложности
модели. Обосновать способ сравнения решений и реализовать новый по отношению
к работам 1–2 механизм. Провести не менее 20 независимых запусков.

## Трек A

Реализовать NSGA-II или другой метод поиска набора Парето. Недоминируемая
сортировка и поддержание разнообразия реализуются самостоятельно;
для NSGA-II нужно расстояние до скопления. Показать фронт и минимум три
характерных решения. Сравнить со взвешенной суммой либо объяснить ограничения
такого сравнения для своей задачи.

## Трек B

Определить язык генотипа и обеспечить корректность потомков. Для программ,
формул, автоматов и наборов правил нужен контроль сложности. Показать минимум
три решения разной сложности и качества; сравнить с подходящей простой моделью.
В символьной регрессии обязательны отдельные обучающая и тестовая выборки.
