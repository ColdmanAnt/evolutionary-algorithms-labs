# ЛР4. Островная модель генетического алгоритма

Вариант 10, Холодков Антон Евгеньевич, группа 517, N=28.

## Запуск

Из этой папки после установки зависимостей корневого README:

```sh
python main.py
python main.py --seed 100 --output scratch_run
python -m unittest -v test_lab4.py
```

Полный запуск: 30 seeds × 4 архитектуры × 3 функции = 360 запусков,
по 30000 оценок. В конфигурации можно менять параметры и список seeds.
Бюджет должен делиться на суммарный размер популяции, а размеры островов
должны быть не меньше 30. Для статистических выводов используйте полную серию,
один seed служит только быстрой демонстрацией.

## Реализация

`main.py`: аналитические функции, BLX-alpha, турнирный отбор, гауссовская
мутация, отражение границ, элитизм, синхронная миграция, статистика и графики.
Острова исполняются последовательно; ускорение на нескольких CPU не заявляется.
Изолированные острова позволяют отдельно увидеть эффект разбиения популяции.
Кольцо и полная связь используют по одному слоту иммиграции на каждый остров.
Полносвязный вариант выбирает лучшего чемпиона среди всех остальных островов.

Результаты: `runs.csv`, `history.csv`, `summary.csv`, `paired_comparison.csv`,
`best_solutions.json`, `convergence_*.png`, `distributions.png`.
`report_content.json` — данные для сборки отчёта PDF.
`proposal.txt` — проект заявки; согласование преподавателем не подтверждено.

## Ответы для защиты

- Генотип и фенотип совпадают: вектор координат в ограниченной области.
- Допустимость обеспечивается отражением; элита сохраняет найденный рекорд.
- Сильный обмен быстрее распространяет удачные решения, но может снижать
  разнообразие. Преимущество оценивается по серии, а не по одному seed.
- Бюджет включает 120 начальных и 249×120 новых оценок. Мигрант уже оценён;
  его копирование не является новым вызовом целевой функции.
- Совпадение seed и версий пакетов не гарантирует одинаковых траекторий на
  разных машинах. Точный двойной повтор проверяется в текущей среде; отличия
  от архива записываются отдельно. Время работы не обязано совпадать.
- Гарантированы границы, счётчик бюджета и сохранение рекорда. Глобальный
  оптимум стохастическим методом не гарантирован.
- При росте размерности нужны исследования масштаба мутации, популяции и
  бюджета. Увеличение числа островов при прежнем размере может ухудшить
  обмен полезными координатами из-за слишком малых подгрупп.

## Независимый аудит

Из корня репозитория:

```sh
python lab4/audit_saved.py
python lab4/audit_saved.py --replay
python lab4/audit_saved.py --strict-archive
```

Во всех режимах строго проверяются 360 сохранённых результатов и 90 000 точек истории, метаданные, статистика, общие начальные показатели, бюджеты, слоты миграции, девять парных сравнений и bootstrap-интервалы, три сохранённых вектора и таблицы отчёта.

`--replay` выполняет каждый из 360 экспериментов дважды и требует точного совпадения результатов между этими повторами в текущей среде. Реальные оценки целевой функции подсчитываются инструментально; проверяются границы, рекорд и независимый скалярный оракул на `math`. Для каждого seed отдельно записываются отличия fitness, истории и доступного архивного вектора от старых данных. Остальные конечные векторы исходно не сохранялись.

Для каждой комбинации функции и схемы применяется фиксированный инженерный предел `abs(mean_повтора − mean_архива) <= max(1e-11, 3 × s_архива / √30)`. Он выявляет дрейф среднего и не доказывает статистическую эквивалентность. `--strict-archive` включает повтор и дополнительно требует совпадения архивных траекторий в пределах `abs=1e-11, rel=1e-10`. [Исходная среда архива](../reference_environment.json) и [политика NumPy](https://numpy.org/doc/stable/reference/random/compatibility.html) объясняют ограничения межплатформенных ожиданий.

Параметры и seed проверяются до начала поиска и создания файлов: дробные размеры, повторные seed, NaN, бесконечности, недопустимые вероятности и несовместимые размеры отклоняются. Миграция требует записываемых массивов с плавающей точкой, чтобы не обрезать дробные координаты. Пробный отчёт отражает фактические размерность, бюджет, топологии, порядок функций, seed и число запусков; серия короче 30 seed помечается как демонстрация.
