# Лабораторная работа № 1 — вариант 10

Холодков Антон Евгеньевич, группа 517, N=28. Размерность 9; функция Михалевича, степень 20, область [0, π]^9.

## Запуск

Требуется Python 3.12+. Создайте и активируйте окружение по [корневой инструкции](../README.md), затем из папки `lab1`:

```bash
python -m pip install -r ../requirements.txt
python main.py
python main.py --seed 100 --sigma 0.02
python main.py --seed 102 --sigma 0.10
python -m unittest discover -s . -p 'test_*.py'
```

Полная серия выполняет 20 независимых запусков для каждой из двух конфигураций ГА и случайного поиска. По умолчанию результаты записываются в `results/`. Архивный план находится в [config.json](config.json); генератор отчёта проверяет соответствие этому плану. Можно передать `--config путь.json --output каталог`; изменение настроек отдельного эксперимента поддержано с `--seed`. Параметр `--sigma` задаётся как доля π. Seed 102 с σ=0,10π воспроизводит лучший результат серии. Время зависит от компьютера; точный повтор проверяется при одинаковых seed, сборке NumPy, окружении и машине.

Для полной серии в отдельном каталоге используйте `python main.py --output scratch_run`. Все новые таблицы, графики и `report_content.json` попадут в `scratch_run/`; корневая копия отчёта сохранённого эксперимента не изменится. Полный запуск без `--output` обновляет архивный `results/` и `lab1/report_content.json`. Приложенный PDF автоматически не пересобирается.

## Состав

- [main.py](main.py): функция, собственный турнирный отбор, SBX, гауссовская мутация, отражение границ, элитизм, случайный поиск, независимый численный ориентир, эксперимент и графики.
- [test_lab1.py](test_lab1.py): 21 проверка формулы, границ, точных квантилей SBX, турнира, маски гауссовской мутации, фактического счётчика оценок, элитизма, воспроизводимости, валидации и изоляции пробного каталога результатов.
- [results/runs.csv](results/runs.csv), [results/history.csv](results/history.csv), [results/summary.csv](results/summary.csv): все серии и агрегаты; [results/summary.json](results/summary.json): те же агрегаты.
- [results/best_solution.json](results/best_solution.json): найденный вектор и его журнал; [results/reference.json](results/reference.json): независимый численный ориентир.
- [results/convergence.png](results/convergence.png), [results/distribution.png](results/distribution.png), [results/algorithm_flow.png](results/algorithm_flow.png): графики и схема.
- [report_content.json](report_content.json): содержимое отчёта для общего сборщика; [PDF-отчёт](../reports/lab1_report.pdf).

Две конфигурации отличаются только масштабом мутации σ=0,02π и σ=0,10π. Все методы получают по 24 000 оценок с учётом инициализации. Численный ориентир использует сепарабельность функции; он не входит в алгоритм ГА и не является доказанным глобальным оптимумом.

## Проверка сохранённых результатов

Из папки `lab1`:

```sh
python audit_saved.py
python audit_saved.py --replay
python audit_saved.py --strict-archive
```

Первый режим независимо проверяет 60 строк запусков, 18 000 checkpoint, начальные популяции, агрегаты CSV/JSON, лучший сохранённый вектор и численный ориентир. Успех выводится только как JSON; нарушение инварианта завершает программу с ненулевым кодом. [audit.json](audit.json) — свидетельство выполненной проверки и список ограничений.

`--replay` запускает каждый из 60 экспериментов дважды в текущем окружении: проверяются точное совпадение seed, fitness, полной истории и конечного вектора между этими двумя запусками, точный бюджет, границы и независимая скалярная формула. Время не сравнивается. Отклонения от старого архива показаны отдельно по каждому seed: число точных совпадений, число совпадений в пределах `abs=2e-12`, `rel=1e-12`, максимальные абсолютные ошибки, первый различающийся checkpoint и общий `archive_equivalence`. Несовпадение не называется совпадением.

Для каждой конфигурации ГА дополнительно действует заранее заданный консервативный regression guard: `abs(replay_mean - archive_mean) <= max(1e-9, 3 * archive_sample_std / sqrt(20))`. JSON показывает исходное среднее, новое среднее, разность и предел. Это проверка грубой регрессии по среднему, а не доказательство статистической эквивалентности. Случайный поиск не имеет обратной связи через отбор, поэтому его fitness и каждый checkpoint по-прежнему должны совпадать с архивом в пределах малого допуска.

`--strict-archive` включает `--replay` и дополнительно требует совпадения каждой траектории ГА с архивом в пределах тех же малых допусков. Во всех режимах дискретные счётчики и внутренние связи сохранённых файлов проверяются строго.

[Политика совместимости NumPy](https://numpy.org/doc/stable/reference/random/compatibility.html) ограничивает гарантии потока одинаковыми сборкой, окружением и машиной. Межплатформенные различия округления могут изменить результаты отбора и последующие траектории ГА; совпадение старого архива и воспроизводимость двух запусков в текущем окружении поэтому проверяются отдельно.

Из исходных 60 конечных векторов был сохранён только общий победитель: именно он сравнивается с исходным вектором. Остальные 59 при повторе проверяются по допустимости и независимой скалярной формуле; утверждения об их сравнении с отсутствующими исходными векторами нет.

Неконечные числовые параметры, дробные размеры и отрицательные seed отклоняются. `--sigma` применяется только с `--seed`; `--seed` и `--replot` несовместимы. Полная серия принимает только приложенный архивный план, чтобы её автоматическое описание не расходилось с реальным экспериментом. Для отдельных изменённых параметров используйте `--seed`.

К защите: пояснить различие генотипа и фенотипа, выбор турнира и SBX, отражение границ, смысл элитизма, учёт бюджета, зависимость выводов от seed и отсутствие гарантии глобального оптимума.
