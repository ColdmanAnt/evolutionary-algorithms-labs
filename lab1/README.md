# Лабораторная работа № 1 — вариант 10

Холодков Антон Евгеньевич, группа 517, N=28. Размерность 9; функция Михалевича, степень 20, область [0, π]^9.

## Запуск

Требуется Python 3.12+. Создайте и активируйте окружение по [корневой инструкции](../README.md), затем из папки `lab1`:

```bash
python -m pip install -r ../requirements.txt
python main.py
python main.py --seed 100 --sigma 0.02
python main.py --seed 102 --sigma 0.10
python -m unittest discover -s . -p 'test_*.py'
```

Полная серия выполняет 20 независимых запусков для каждой из двух конфигураций ГА и случайного поиска. По умолчанию результаты записываются в `results/`. Архивный план находится в [config.json](config.json); генератор отчёта проверяет соответствие этому плану. Можно передать `--config путь.json --output каталог`; изменение настроек отдельного эксперимента поддержано с `--seed`. Параметр `--sigma` задаётся как доля π. Seed 102 с σ=0,10π воспроизводит лучший результат серии. Время зависит от компьютера; численные результаты при той же версии NumPy и seed воспроизводятся.

Для полной серии в отдельном каталоге используйте `python main.py --output scratch_run`. Все новые таблицы, графики и `report_content.json` попадут в `scratch_run/`; корневая копия отчёта сохранённого эксперимента не изменится. Полный запуск без `--output` обновляет архивный `results/` и `lab1/report_content.json`. Приложенный PDF автоматически не пересобирается.

## Состав

- [main.py](main.py): функция, собственный турнирный отбор, SBX, гауссовская мутация, отражение границ, элитизм, случайный поиск, независимый численный ориентир, эксперимент и графики.
- [test_lab1.py](test_lab1.py): 18 проверок формулы, границ, точных квантилей SBX, турнира, маски гауссовской мутации, фактического счётчика оценок, элитизма, воспроизводимости, валидации и изоляции пробного каталога результатов.
- [results/runs.csv](results/runs.csv), [results/history.csv](results/history.csv), [results/summary.csv](results/summary.csv): все серии и агрегаты; [results/summary.json](results/summary.json): те же агрегаты.
- [results/best_solution.json](results/best_solution.json): найденный вектор и его журнал; [results/reference.json](results/reference.json): независимый численный ориентир.
- [results/convergence.png](results/convergence.png), [results/distribution.png](results/distribution.png), [results/algorithm_flow.png](results/algorithm_flow.png): графики и схема.
- [report_content.json](report_content.json): содержимое отчёта для общего сборщика; [PDF-отчёт](../reports/lab1_report.pdf).

Две конфигурации отличаются только масштабом мутации σ=0,02π и σ=0,10π. Все методы получают по 24 000 оценок с учётом инициализации. Численный ориентир использует сепарабельность функции; он не входит в алгоритм ГА и не является доказанным глобальным оптимумом.

## Проверка сохранённых результатов

Из папки `lab1`:

```sh
python audit_saved.py
python audit_saved.py --replay
```

Первый режим независимо проверяет 60 строк запусков, 18 000 checkpoint, начальные популяции, агрегаты CSV/JSON, лучший сохранённый вектор и численный ориентир. Второй дополнительно повторяет все 60 запусков и сравнивает каждый итоговый fitness и полную историю. Успех выводится только как JSON; несовпадение завершает программу с ненулевым кодом. [audit.json](audit.json) — свидетельство выполненной полной проверки и список ограничений.

Из исходных 60 конечных векторов был сохранён только общий победитель: именно он сравнивается с исходным вектором. Остальные 59 при повторе проверяются по допустимости и независимой скалярной формуле; утверждения об их сравнении с отсутствующими исходными векторами нет. Время не сравнивается между повторами. При повторном вычислении fitness, значений истории и сохранённого вектора используются абсолютный допуск 2·10^-12 и относительный 10^-12: это учитывает различия округления libm между платформами. Seeds, номера поколений, числа оценок и длины историй должны совпасть точно; внутренние связи сохранённых CSV/JSON проверяются без ослабления. JSON отдельно показывает фактическое число точных совпадений, число совпадений в пределах допуска и максимальные абсолютные ошибки, включая координаты сохранённого победителя.

Неконечные числовые параметры, дробные размеры и отрицательные seed отклоняются. `--sigma` применяется только с `--seed`; `--seed` и `--replot` несовместимы. Полная серия принимает только приложенный архивный план, чтобы её автоматическое описание не расходилось с реальным экспериментом. Для отдельных изменённых параметров используйте `--seed`.
