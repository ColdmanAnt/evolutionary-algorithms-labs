# Лабораторная работа 2

Генетический алгоритм для дискретной задачи с ограничениями.

**Статус:** структура подготовлена, реализации и результатов пока нет.
Индивидуальный вариант задаётся в [variant.json](../variant.json).

## Вариант 16

**Раскраска графа с минимизацией числа цветов и штрафом за конфликты.**
Генотип — целочисленный вектор цветов вершин. Конфликт возникает, когда
концы ребра имеют одинаковый цвет. Входной граф должен содержать не менее
**20 вершин**. Конкретный граф, штраф и способы обработки ограничений
будут определены при реализации и записаны в конфигурации и отчёте.

## Требования

- Дискретный генотип, соответствующий предметной задаче, и декодирование при необходимости.
- Хотя бы один специализированный оператор вариации.
- Проверка всех ограничений и обеспечение либо восстановление допустимости.
- Приложенные входные данные с описанием источника или генерации и seed.

## Эксперименты и сдача

Провести не менее 20 запусков. Показать два допустимых и два недопустимых решения.
Сравнить два подхода к ограничениям и два содержательно разных оператора,
если они применимы к выбранному представлению. Сравнить с конструктивной
эвристикой или случайным допустимым поиском при сопоставимом бюджете.
Представить лучшее решение в понятной предметной форме.

Код — `src/`, данные — `data/`, параметры — `configs/experiment.json`,
результаты — `results/`, графики — `figures/`, отчёт — [REPORT.md](REPORT.md).
Команды установки и запуска будут добавлены после реализации.
